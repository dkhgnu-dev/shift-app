## 実装上の注意

- モバイル用 `.header .btn { width: 100%; }` が月移動ボタンへ適用されないよう、月度ヘッダー内では幅を明示的に戻す。
- ダッシュボード表は第1列がドラッグ記号、第2列が氏名である。DOM構造を整理するか、第1・第2列それぞれのstickyと`left`位置を正しく設計する。
- 横スクロールコンテナと縦スクロール祖先を確認する。CSS値だけでなく、実際にスクロール後のセル座標が固定される構造にする。
- jsdomテストを「実機レスポンシブ確認済み」の代替として報告しない。DOMロジックテストとブラウザレイアウト検証を分ける。
