# P1 / P2草案: Cycle 11「6連勤＆インターバル警告＆左固定氏名列のワンクリック折りたたみ・うっすら名字表示」設計書

## 背景と戦略（さらなる実戦的UX・視認性拡張）
現行 (v4.35) のスマホ表示最適化に続き、カズマ総監督からのさらなる洗練・実用性向上の指針に基づき、**① シフト計画上の労務・体力リスク（6連勤以上、および遅番からの早番短インターバル）をリアルタイムに優しく知らせる健全性アラート機能** と、**② スマホのシフト表示領域を究極大拡張すべく、左側氏名列を極限まで折りたたみ、名字だけをうっすら透かして残す画期的アシストUI** を Cycle 11 として統合実装します。

動的な列幅のトグル変化およびセルごとの警告表示状態が加わることから、スマホの横スクロールスワイプやセルのスワップタップ等との干渉、および重厚化しつつある自動テスト（140件）のタイムアウト問題・回帰バグを防ぐため、**Air(P1草案) ➡ Dex(P2 事前技術監査・テスト方針最適化) ➡ CC(P3 全実装)** の堅牢かつ最高最速の安心ラインにて手戻りゼロを実現させます。

## 1. コア仕様およびUI機能要件 (MUST)

### (1) リアルタイム・シフト健全性チェッカー（連勤 ＆ インターバル不足アラート）
シフトの自動生成後、ならびにユーザーがタップ直接時間編集やスワップ入れ替え・Undo/Redoを実行した際、フロントエンド側でリアルタイムに該当従業員の勤務列をチェックして警告マークを美しく描画すること。

- **A. 「6連勤以上」警告アラート**:
  - **判定ロジック**: 休日（「休」または実質作業のない空欄・未配置等）を挟まずに、**6日以上連続で勤務（①〜③やカスタム時間など）が連続している区間** を検出すること。
  - **表示方法**: 連続6日目以降（または連続する該当期間すべてのセルなど）に、注意を促すソフトな警告印（例: `⚠️ 6連勤` アイコンやハイライトアクセント）を配置。セルをクリック／タップした編集画面やヒントでも「現在6日以上の連続勤務中です」と認識できるようにすること。
- **B. 「遅番からの早番（休息インターバル不足）」警告アラート**:
  - **判定ロジック**: 前日 ($N$ 日目) の終了予定が遅め（目安として終了 22:00〜24:00 以降の「遅番・夜間」勤務）でありながら、翌日 ($N+1$ 日目) が朝一・早め（目安として開始 8:15〜9:00 頃などの「早番」）となる、クローズ後オープン連続（休息時間が極限まで短い状態）を自動特定すること。
  - **表示方法**: $N+1$ 日目の該当セル（または過酷接続の双方セル）に判別可能なバッジ・アイコン（例: `⏰ 休息短` または `遅→早` など）を表示し、スワップ交換での負荷緩和を促すこと。
- **リアルタイム即応性**: 各種計算は Undo/Redo の状態移動およびタップ手塗りに連動し、修正された途端にアラートが解除・再描画されること。

### (2) ワンクリック氏名列「極狭折りたたみ ＆ うっすら名字透かし表示」機能
スマートフォンおよびPCにて、シフト表そのものを限界領域まで広く見渡すための極上の省スペース設計を取り入れます。

- **A. 折りたたみトグルボタン**:
  - テーブル左端・氏名列ヘッダー付近に、折りたたみ／展開をスムーズに切り替えるボタン（例: `◀` / `👁️` / `折畳` 等）を設置すること。
- **B. 折りたたみ状態時の「幅 24〜32px 極薄化 ＆ うっすら名字のヒント提示」**:
  - レスポンシブ性を重視して名前列を完全に消し去る (`display: none`) と、横にスクロールして日程を進めた際に「今の行がいったい誰のシフトか」を認知できなくなる迷子事故が発生します。
  - この問題を根本解決するため、折りたたみ時の横幅を **わずか 24px 〜 32px 程度** へ限界ミニマム化し、その狭小スペースの中に **該当スタッフの「名字（姓名の最初・スペース手前の単語、例: 「鈴木 花子」における「鈴木」等）」を半透明（`opacity: 0.5〜0.7` 等）やコンパクトな縦書／省スペース字形などでうっすらと表示し続ける** こと！
  - これにより、シフト表面積を 100% 近く堪能しながらも、「あ、この行はうっすら見える鈴木さんのものだな」と安心・正確に把握し続けられる究極の閲覧体験を提供します！
- **C. 通常サイズへの即時復元**:
  - トグルボタン、あるいは折りたたまれた氏名ヘッダー等を再タップすることで、直ちに現行の 80〜85px 基本幅（従業員情報ドロワーアクセス等）へスムーズに復帰・展開すること。

## 2. 厳守すべき共存義務および安全保証条件 (MUST & Safety)

- **バックエンド自動生成への完全非干渉**:
  - 本件の連続勤務・インターバル判定および折りたたみ状態は純粋にフロントエンド側 (`frontend/`) における快適な計算・レンダリングとして仕上げること。`backend/` の数理・最適化ロジック等には一切干渉しないこと！
- **既存の最強機能群の完全継承と無傷連動**:
  - 最適化履歴スナップショット（Undo/Redo 20件保持）
  - セル直接タップ／クリックでのアドホックな時間・種類微調整ポップオーバー
  - スマホでの無干渉・2点タップスワップ（入れ替え）システム
  - 月間目標計上時間 (`targetHours`) ベースの配置差分カラーバッジと未設定サポート
  - 100% PC Zoomフィット ＆ スマホ時アクションボタンのハンバーガーメニュー格納状態
- **恒久テスト (140件超) のタイムアウト撲滅＆確証**:
  - 全ての現行単体・結合テストにおいて 0 タイムアウトのスピード連続PASSを維持すること。
  - 本サイクルの「6連勤・遅番早番アラート検知関数」「名字抽出および折りたたみ切替状態」のテストを追加し、**全件高速フルPASS（緑化）** を達成させること。
- **バージョン表記のアップデート**:
  - 本作業完了に伴い、アプリおよびヘッダー等の表示バージョン番号を **`v4.36`** に刷新すること！
