# P1 / P2草案: Cycle 12「手動登録シフトの上書き防止（緊急バグ修正）＆ワンクリック一括スタンプ（塗り）登録機能」設計書

## 背景と戦略（緊急課題と革新インターフェースの統合調和）
カズマ総監督より、実地運用における最大の痛点と未来を見据えた超効率UXのご指示を拝領いたしました。
1. **緊急仕様修正**: 「手動でシフトや休診などを前もって登録した後に自動作成（最適化シフトを生成）を実行すると、手動でセットした内容が一枚にわたり一瞬で上書き・破壊されてしまう」という重大課題です。これでは事前の手動登録が形骸化・徒労となってしまうため、**手動で配置されたシフト・休みを「確定済（ロック／保護対象）」として自動計算時にも完全保護する仕様** へ最優先で緊急是正します。
2. **快適・爆速の一括スタンプ登録UI**: 毎回セルをタップしてモーダルやドロップダウンを開き、時間を何度も選択するのは自動生成前の入力負荷をはなはだ跳ね上げます。そこで、「遅番（15:30〜24:00）」「早番」「希望休」などをあらかじめ筆として手元で選択しておくことで、以降は **テーブルのセルをポンッとワンクリック／短タップするだけで連続・即座に当該シフトや休みが塗り付けられる「スタンプ（ペイント）登録モード」** を一気開発いたします。

本タスクは、① 危険領域である「シフト自動生成ロジックと固定シフト（手動配置）の連携・非上書き制御」を直接取扱うこと、② 現在 main ブランチで待機中である v4.38 の自動生成ロジック調整 (`backend/shift_solver.py`) の未確認監査との並行検証が必要であること、③ ペン・塗り込み操作とスマホ横スワイプおよび Undo/Redo 履歴との反応競合を除去すべきことから、**Air(P1草案) ➡ Dex(P2 事前自動ロジック＆タッチセキュア技術監査) ➡ CC(P3 全実装)** の正規セキュアラインを強制適用・最速直進させます。

## 1. コア仕様およびUI機能要件 (MUST)

### (1) 【緊急優先】手動登録シフトおよび希望休の完全不滅（自動計算時の非上書き保護）
- **原因の核心と防衛方針**: 現状の「最適化シフトを生成（自動作成）」および「空欄自動作成」を実行する際、あらかじめマトリクス上に入力されている希望休・手動入力時間・連動状態を自動生成の数理最適化処理側で未判定・またはリセット上書きしているバグおよび仕様ミスが存在します。
- **実装あるべき姿**:
  - マトリクス配列内で、すでにユーザーによって明示的に配置されたすべての値（基本シフト ①②③、カスタム時間設定、遅番・早番等、希望休「休」など）は、**「確定・据え置き・不可避ロック制約 (Fixed/Locked Constraints)」** として明確にマークまたは抽出すること。
  - バックエンド自動生成 (`backend/shift_solver.py` 等) またはフロントエンドの payload 送受信ループおよび空欄補完を改修し、**手動等で前もって値が入っているセルは1ミリたりとも上書きせず保持し、未入力・空欄のセルのみに最適化計算や空欄自動配置を行う** 堅牢な構造へ緊急修正すること！
  - これにより、「前もって店長が肝心な早番や休みの場所を見做ってスタンプし、最後に取り残された空白の枠だけを『AI自動最適化ボタン』へ賢く補完させる」という理想的な運用を完全に成立させること！

### (2) 「ワンクリ一括スタンプ（塗りつき）」登録モード（ペイントインターフェース）
- **A. パレットコントローラー（スタンプ筆持ち器）の構築**:
  - 画面上部コントローラーエリア（Undo/Redo 付近、またはワンクリックで開くスタンプバー等）に **「🖌️ 一括スタンプ（塗り）モード」** のトグル、および登録する値を選べるパレットを配置すること。
  - **パレット候補**: 「希望休 🎲/休」「早番 (例: 8:15〜17:30)」「中番」「遅番 (例: 15:30〜24:00)」や、直前にユーザーが手塗りで作ったカスタムシフト時間等を自由に「現在のスタンプ針（アクティブ筆）」として選択可能とすること！
- **B. ワンクリック・タッチ連打・連続スタンプレスポンス**:
  - スタンプモード起動中は、従来のようにセルをタッチした際に毎回「詳細ポップオーバー／変更ドロップダウン」を開く動作を一時抑止する！
  - 代わりに、選び抜いたスタンプ筆を装着した状態でセルをポチッとワンクリック（スマホでは短くワンタッチ）するだけで、**そのセルへ瞬時に当該シフト時間・希望休がスタンプ（刻み付け・塗り替え）される超爆速インターフェース** に進化させること！
- **C. スマホのスワイプ誤塗布抑止 ＆ Undo/Redo 連動**:
  - 横スワイプスクロールを行おうとして指が滑った際には、移動検知（8px以上の判定や pointercancel）によりスタンプ塗布を即座に無効化（干渉防止）すること。
  - すべてのスタンプ操作は原子的に Undo/Redo の 20件歴史スタックに記録され、「連打しすぎて間違えた場所を染めてしまった！」としても、即座に 1発 Undo で復元させられるよう万全のお守りを保つこと！

## 2. 厳守すべき共存義務および安全・バージョン監査 (MUST & Safety)

- **自動生成ロジック変更の事前レビュー義務化 (Dex P2/P4 監査)**:
  - 今回の手動入力シフト非上書き制御は自動生成関連処理にかかわるため、`backend/shift_solver.py` や自動生成受け入れペイロード等への改修を伴う場合、Dex による厳格なコード＆テスト確認を受けること。
  - また、v4.38 の「土日祝50%以上出勤」「時間帯区分均等配分」と干渉しないよう一括してロジック検証を行うこと。
- **既存の最強機能群の完全継承**:
  - ワンクリ氏名列折りたたみ（24〜32px 極薄＆うっすら名字透かしヒント）機能
  - 6連勤以上＆遅番からの早番（休息インターバル不足）警告アラート
  - 月間目標計上時間 (`targetHours`) 過不足カラーバッジ
  - スマホ表示時アクションボタンのハンバーガーメニュー格納 ＆ PC 100% Zoom フィット
- **タイムアウトなし恒久テスト (全140件超) の即パス維持**:
  - 全ての単体・統合テストが 0 タイムアウトの爆速連続PASSとなることを維持し、「手動入力したセルが自動作成でも上書きされないこと」「スタンプモード時にセルクリックが正しく連打上書きされること」の自動テストを追加拡張の上、全件フルPASSを証明すること！
- **バージョンゲート＆採番方針**:
  - 実装完了に伴い、必ず画面の PC/スマホ 2か所および `CURRENT_STATUS.md` を最新の次期連番 **`v4.39`** （または実装時点の現行値 + 1）に更新し、`node scripts/check_version_gate.mjs` をパスさせてから進めること！
