# P1 / P2統合実装指示書: Cycle 10「スマホ版UIの全面領域拡大およびボタン配置最適化」

## 概要と背景
カズマ総監督より、現在開発中のシフト作成ツール（現 v4.33）におけるスマートフォン（max-width: 768px）表示時の表示面積圧迫についてさらなる大刷新の改善指示が発出されました。
本サイクル（Cycle 10）では、これまで画面下部スペースを専有していた3大アクションボタンのハンバーガーメニューへの退避・統合、コンテナ外枠余白の極小化、そして氏名固定列の 80px〜85px への一層のスリム化を統合実行し、**「スマホでも全幅を余すところなくダイナミックに使える最強のシフト見え方」** を完成させます。

※本調整は画面レイアウトおよびスマホ領域表示最適化の純粋なUI改修であり、保存処理や計算ロジック破壊を伴う危険領域（Stop Conditions）には当たらないため、Air(P1/P2統合) より実装担当 CC(P3) へ直接委任・着手合図を出します。
（※総監督会議レジュメの「Navi」は、当チームエンジニアリング体制における実装専任エージェント「CC(P3)」へ正規変換いたします）

## 1. 策定・指示仕様の要件定義 (MUST)

### ① 下部固定アクションボタン群のハンバーガーメニュー化
- **対象アクション**: 「希望休ランダム入力」「空欄自動作成」「最適化シフトを生成」の 3 つのアクションボタン。
- **スマホ表示時 (max-width: 768px) の動作**:
  - 画面下部に固定／常設されているこれら 3 ボタンを **スマホでは完全に非表示** （`display: none;` 等による表示エリア圧迫除去、あるいはモバイル時レンダリングの省き等）に構成変更する。
  - 代わりに、左上に配置されている **ハンバーガーメニュー (≡)** ドロワー／モーダル内部の専用メニュー項目として、これら 3 つのアクション（例: 「🎲 希望休ランダム入力」「🪄 空欄自動作成」「🚀 最適化シフトを生成」等）を統合・展開する。
- **PC表示時 (min-width: 769px) の維持**:
  - PC等の大画面側では、従来の直感的な直接ボタンアクセシビリティ（表示と操作導線）を崩さずに維持すること！

### ② 外枠余白（コンテナパディング＆マージン）の極小化
- **スマホ画面全領域ダイナミックフル活用**:
  - テーブル全体および画面外枠を囲んでいるメインコンテナにおける不要な白枠・周囲余白を根絶すること。
  - スマホ表示時 (max-width: 768px) に限り、左右上下のパディング・マージンを **最小値 (目安: padding/margin を 0px 〜 2px〜4px 程度)** へ圧縮再構築すること！

### ③ 「氏名」列のさらなるスリム化（80px 〜 85px 領域拡張）
- **左側固定列幅の極大圧縮**:
  - 左側に固定・維持されるスタッフ氏名列の横幅について、現行（約 100px〜105px）の壁を破り、**目安: `80px 〜 85px` 程度へ限界まで削り込ませる** こと！
  - 氏名セルの内側余白（`padding-left` / `padding-right` やテキスト境界スペース）を最小限の幅（2〜3px等）に調整し、文字あてえんも防ぎながらメインである **右側シフト表示（日付列）エリアへ極限まで幅を譲り渡す構造** とすること。

## 2. 非改変領域・安全防衛基準 (Regression Protection & Testing)

1. **機能的継承（壊してはいけない世界観）**:
   - バックエンド API および最適化通信・数理計算の設計は変更ゼロ（不干渉）。
   - Cycle 9 までで磨き抜かれた以下の超高機能は 100% 動かすこと：
     - `Undo / Redo` 履歴スナップショット（20件までの原子的一貫性）
     - スマホ版での「スワップ（入れ替え）機能」「タップ直下の即席編集パネル」と横スワイプスクロールの完全無干渉。
     - 氏名タップ時の「従業員詳細情報ドロワー（勤務属性や時間目標の閲覧等）」起動動作。
     - 月間目標時間 (`targetHours`) ベースの過不足差分バッジ表示機能。
2. **自動テスト (135件超) と品質維持**:
   - アクションボタンがスマホにおいてメニュー化されることに起因するテストのクエリ（例: `getByText("希望休ランダム入力")` 等）での偽陰性エラー・画面検証エラーを出さないように注意すること（テストのレスポンス条件／セレクタ補強対応を行ってもよい）。
   - Vitest 単独・全体実行を行い、全 135 件以上の自動テストが **タイムアウトなし・フルPASS** であることを証拠として記録・維持すること。
3. **バージョン番号の繰り上げ**:
   - 画面フッターまたはヘッダー・設定等における表示バージョン番号を **`v4.34`** に明確にアップデートすること！
