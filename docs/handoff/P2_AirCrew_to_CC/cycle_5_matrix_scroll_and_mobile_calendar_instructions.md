# P2 指示書: Cycle 5 マトリクス表の固定＆左右スクロールボタン搭載とスマホカレンダー統合

## 背景・目的
前サイクルの完成を継続し、以前「心臓部ができた後に持ち越し実装予定」とされていた大機能 **「項目4：画面固定 ＆ 左右スクロールボタン（◀ ▶）」** を一気に実装します。

現在のスマホ表示は「1日ずつの縦長カード表示」となっており、月間の空きや勤務全体を把握できず極めて使いづらい状態です。さらにヘッダー部に「`2026` / `年7` / `月度`」と謎の3段改行および巨大な無駄余白が発生しています。

本サイクルでは以下のUI/UX改修を通し、**スマホとPC両方で「名前と日付を固定したままスイスイ快適に横スクロールできる月間マトリクス表」** を完成させてください。

## CC（P3 実装エンジニア）への具体的指示

### 1. スマホ上部ヘッダーの巨大余白および文字段落（改行）の解消
- 月度切り替えボタンと表示（例: `<` `2026年7月度` `>`）が含まれるコンテナにおける大きな縦間隔や余白を削減してください。
- スマートフォンの細い解像度（320pxや375px）であっても「年」「月度」などが3段の縦割れにならないよう、`display: flex; flex-direction: row; align-items: center; justify-content: center;` や `white-space: nowrap;` 等を用いてスマートな1行表示（例: `◀ 2026年 7月度 (6/16～7/15) ▶` またはコンパクト設計）に直し、デッドスペースを徹底削減すること。

### 2. スマホ版「1日限定ビュー」の廃止とカレンダーマトリクス統合
- スマホ幅（Narrow解像度等）において、これまで強制描画されていた「単日ごとの個人カードビュー（日付を選択して1日分のシフトが出る構造）」を完全に終了させてください。
- スマホの縦スクリーンであっても、PC同様の **「全員の1ヶ月分が表形式で確認できるマトリクス表（カレンダービュー）」** を常に描画させ、指でのタッチおよびスクロールボタンで操作可能にすること。

### 3. 表の画面固定（Freeze Panes / Sticky）の適用
大きなマトリクス（24名×30日〜31日分）をスクロールしても目印を見失わないよう、表構成（`table.shift-table` 等またはコンテナエリア）に確実な固定を組み込む：
- **上部ヘッダー（日付行・時間ラベル行）の固定**: 
  - `position: sticky; top: 0; z-index: 20; background: #fff;` 等のスタイルで縦スクロール時に固定。
- **左列（スタッフ名前・役職・稼働数サマリ列）の固定**: 
  - 最初の列（氏名バッジおよび合計値）に対して `position: sticky; left: 0; z-index: 30; background: #fff; box-shadow: 2px 0 5px rgba(0,0,0,0.05);` 等を適用し、右側への横スクロール時に常時左側に据え置き固定すること。
- **左上端の角（氏名欄ヘッダーセル）の二重固定**:
  - 縦横同時スクロール時も維持するため、`position: sticky; top: 0; left: 0; z-index: 40; background: #fff;` を付与。
- *※重要*: `sticky` エレメントには必ず**不透明な背景色 (`#fff` など)**を付与し、スクロールしたマスの文字（休、①等）が後ろから透けて見えないよう防止すること。

### 4. 左右スクロール移動ボタン（◀ ▶）の設置
- スマホやPCでもワンクリック／タップで快適にカレンダーを左右へ移動できるよう、表の真上やヘッダー直下等の目立つナビ位置に、マトリクススクロール領域（`overflow: auto` コンテナ）をターゲットにした **左右移動ボタン**（例： `◀ 前週 / 後ろ週 ▶` または `◀ 左へスクロール / 右へスクロール ▶` など）を取り入れてください。
- React側で `tableContainerRef.current.scrollBy({ left: -350, behavior: 'smooth' })` / `scrollBy({ left: 350, behavior: 'smooth' })` のような滑らかなアクションを紐付けること。

### 5. バージョン更新
ヘッダーおよび画面表示されているアプリバージョン表記を **`v4.20` から `v4.21`** へ更新してください。

## 検証条件 (MUST)
1. 自動テスト・コンパイル成功
   - `npm --prefix frontend test` が正常にパスすること
   - `node frontend/test_time_utils.mjs` で 33テスト全件通過すること

   - ブラウザの狭幅（320/375px/768px）時に、これまでのような使いにくい「1日のカード一覧」ではなく、**横スクロール可能な全員分の月間マトリクス表が直接表示されていること。**
   - 「2026年 7月度」などの日付・締め表記が美しく一行におさまっており、上にあった大きすぎる無駄スペースがなくなっていること。
   - スクロールを発生させた際、左の「名前列」と上の「日付列」が所定の位置にシームレスにピン留めされており、背後が透けないこと。
   - 設置した左右スクロール補助ボタン（◀ ▶）を押すと、即座に快適に表が左右へスイングすること。
