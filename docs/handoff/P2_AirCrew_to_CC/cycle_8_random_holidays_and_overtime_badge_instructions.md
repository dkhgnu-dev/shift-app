## CC（P3 実装担当）への詳細開発指示

### 1. 「🎲 希望休ランダム自動入力（検証用テストジェネレーター）」ボタンの実装
シフト検討時の仮入れ時間を省くため、ワンクリックで全スタッフの希望休（「休」）をリアルに散らして配置できる便利ボタンを新設してください。

#### ◆ 配置位置・デザイン
- 画面上部（`activeTab === 'dashboard'` 時の操作アクション群、「空きコマ最適自動作成」等ボタンの並びあるいはすぐ隣、またデバッグ／ヘルパーツール群領域）に、以下のような見栄えの良いボタンを設置：
  - ボタンスタイル: 例 `背景パープル〜アイゴーディープブルー系`、ラベル: `「🎲 希望休ランダム入力」` または `「🎲 テスト希望休をばら撒く」`

#### ◆ 動作・仕様ロジック
- クリック時、既存データの意図せぬリセットを防ぐため、確認ダイアログ（`window.confirm("現在の各従業員の「休」設定をクリアして、テスト用のリアルな希望休（「休」）を自動で散りばめますか？")` 等）を表示させる。
- 承認後、全従業員（現在24名等）について、選択されている対象期間（30〜31日間）のうちからランダムに「休」（または希望休マーカー）をスマートに設定：
  - 👤 **正社員（あるいは最初の一定層・週休等の標準契約社員等）**: 当月内に **「約 2日 〜 4日」** 分の希望休を分散配置！
  - 👥 **遅パ / パート・アルバイト層（短期間契約やパート・遅パバッジ保持者）**: 当月内に **「約 5日 〜 8日」** 分の「休」をランダム配置！
  - ※ 1日あたり全員が丸ごと休まないように分散アルゴリズム（各日の休み人数が偏り過ぎない簡素なチェック等）があれば最高ですが、第一にテストデータとして最速でキレイに即時展開・プレビューされる実質状態を取り入れ、状態（state）を更新すること！

### 2. 「📊 残業・不足時間のリアルタイム超過不足メーター ＆ カラー警告」システム
各スタッフの現在の累積労働時間（実績計算値）が、既定の標準・目標労働時間（例: `contractHours` や目標 `80.0h`、`160.0h` など、各従業員データが保持する時間目安、もしくは既存の勤務表に現れる目標対等）と比べて **「何時間多いか（残業警戒） / 何時間足りないか（出勤日数・不足）」を自動的に差分計算し、即座に色分け表示**してシフト管理者へ警告・ガイドするUIを追加してください。

#### ◆ 差分計算基準と色分け（スタイリング）
実績時間（現在シフトセルに割り振られている時間数の総計） minus 標準・目標時間 ＝ 過不足差分
- 🔴 **超過・残業注意状態 (差分 > +2.0h など超過)**
  - 例: `+12.5h (超過⚠️)` または `+12.5h 残業`
  - 文字色: `#DC2626` や `#D97706` (朱赤・アンバー等)、必要に応じ薄紅の警告タグチキ `background: #FEF2F2` 等でひと目で目立たせる！
- 🔵 **時間・シフト不足状態 (差分 < -2.0h など下回り)**
  - 例: `-8.0h (不足)` または `-8.0h`
  - 文字色: `#2563EB` (さわやかで目立つブルー等)、背景 `background: #EFF6FF` 等
- 🟢 **基準内・良好状態 (-2.0h 〜 +2.0h またはちょうど 0)**
  - 例: `±0.0h (標準)`
  - 文字色: `#059669` (グリーン等) または標準文字色

#### ◆ デバイス・環境ごとの「極上住み分けUI（最適配置）」
Cycle 7 の遺産を強力にフル継承してください！
- 💻 **PC（大画面 `!isMobileView`）環境**:
  - 左側固定の従業員氏名セルの下やサマリー表示（「16日 / 80.0h」などのバッジ近辺）に、**小さな差分タグ（例: `(+12.5h⚠️)` や `(-8.0h不足)`）をインライン接続または2段目・サマリー横へスッキリと添える！** 一発で縦に眺めて各人のバランスを把握可能にする。
- 📱 **スマホ（小画面 `isMobileView`）環境**:
  - **最重要ルール：スマホ表示時の「左固定列 100〜110px 超コンパクトサイズ」には絶対に差分テキストを表示しないこと！（横幅を食わないよう徹底守護）**
  - その代わりに、Cycle 7で完成した **「氏名セルをタップ（クリック）して立ち上がる軽量ポップオーバー/ドロワーカード」の中**の「累積実績エリア」の下に、**「【月間目標との差分・残業判定】 +12.5時間 ⚠️残業超過注意！」** といった立派で大きく見栄え抜群のカードメーター（棒状カラーインジケーターまたは大きく色分けされた数字タグ）をデコドンと豪華に組み込むこと！ これによって圧倒的に整ったキレイなカレンダー表を維持しつつ、最強の管理インサイトをもたらします！
