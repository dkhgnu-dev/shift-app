# P2 指示書: Cycle 7 画面表示面積の最大化と「一画面ジャストフィット ＋ ズーム連動フロートスクロール」の実現

## 背景・目的
Cycle 6 においてエレガントな半透明フロートスクロールボタンが組み込まれましたが、現状のPC表示（スクショ確認時）には以下の課題があります：
1. **余白が多すぎて、シフト表の表示される面積が小さく見にくい。**
   - カード周囲の巨大なマージンやパディング等により、上下左右に無駄なラベンダー背景エリアが多く残り、肝心のシフト表が窮屈になっている。
2. **デフォルト状態で表が横に開きすぎており、最初から全体像が見られない。**
   - ユーザーの本物の理想は **「デフォルト（初期表示）では一画面（幅）の中に1ヶ月の全日程がジャストインして収まり、全体を見下ろせる状態」** です。
3. **ズーム（拡大・縮小）機能の導入による「最高の使い分けUX」の実装。**
   - 普段は一画面フィット（スクロール不要＝フロートボタン出番なしで非表示）で全体を確認。
   - 細かく編集やチェックしたい時は **「ズームボタン（＋／ー）」** でマス目を一気に拡大！
   - **ズームして横が画面に入りきらなくなったその瞬間に、Cycle 6の「半透明フロート矢印ボタン」が魔法のように浮かび上がり、横の非表示エリアへスイスイスクロールして確認・操作できる状態**を構築すること！

## CC（P3 実装担当）への技術・詳細指示

### 1. シフト表示コンテナの余白削減と「画面面積最大化（ワイドエリア化）」
- `App.jsx` と `index.css` にて、`activeTab === 'dashboard'` 時のメインカードやテーブル外枠の過剰なマージン・パディング（`padding: 24px` 等）や余計な空き空間をシェイプアップしてください。
- テーブルを包むスクロールコンテナが、ウィンドウの幅および高さ（`height: calc(100vh - ヘッダー分等)` など）の許す限り **画面いっぱいに広く堂々と描画されるように** 構造とコンテナのサイズ設定を最適化すること。

### 2. ズーム（拡大縮小）コントロールパネルの設置
- ヘッダーまたはテーブル最上部バー（月度切替や「最適化シフト生成」の近辺、またはテーブル右上の便利な目立つ場所）に、ワンクリックで表の大きさを可変させられる **ズームコントローラー** を配置してください。

```jsx
// コントローラー構成例 (＋/ー ボタンやプリセット)
<div style={{display: 'flex', alignItems: 'center', gap: '4px', background: '#F3F4F6', padding: '2px 6px', borderRadius: '8px'}}>
  <button className="btn-zoom" onClick={() => handleZoom(-1)}>➖</button>
  <span style={{fontSize: '0.85rem', fontWeight: 600, minWidth: '50px', textAlign: 'center'}}>{zoomLevel}%</span>
  <button className="btn-zoom" onClick={() => handleZoom(1)}>➕</button>
  <button className="btn-zoom-reset" onClick={() => setZoomLevel(100)}>一画面フィット</button>
</div>
```
- **倍率ステージの案:**
  - `100% (デフォルト: 一画面フィット仕様)`
  - `125% (やや拡大)`
  - `150% (快適編集拡大)`
  - `200% (特大サイズ)`
  - ※必要に応じて小画面用 `85%` なども実装可

### 3. デフォルトの「一画面ジャストイン（100%表示）」チューニング
- `zoomLevel === 100` の際、PC標準解像度（幅1280px以上など）で全30/31日分と左氏名列が横の横断限界を出ないように（オーバーフローしないように）、セルの最小幅（`min-width: 38px〜42px` 等、あるいはフォントサイズ `0.75rem` など）や CSS `transform: scale(...)` またはインライン `fontSize` / `padding` の減衰比率を計算し、**「開いた瞬間に一ヶ月の全体像がすべて視野に飛び込む状態」** にデザインすること。

### 4. 半透明フロートスクロールボタンとの完全連動（スマート可視化回路の徹底）
- コンテナ内の横スクロール判定（`scrollWidth > clientWidth`）と `onScroll` を強力に結合させる：
  - **「100%ジャストフィット」で横が全くオーバーフローしていない状態のときは、半透明のフロートスクロールボタン（◀ ▶）を完全に非表示にさせること。**
  - **ズームボタン等で拡大し、横幅がウィンドウから見切れた（`scrollWidth > clientWidth`）瞬間にはじめて、半透明フロートボタン（右や左）が優雅に姿を現し、クリックでスクロール稼働するように連動させること！**
  - ※既存のa11y・タブ復帰時の計算および左固定カラム（40px + 氏名等）からのミリ単位ズレ対策を守ること。

### 5. バージョン更新
アプリの表示バージョンを **`v4.25` から `v4.26`** に引き上げてください。
