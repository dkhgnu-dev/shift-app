# P2 指示書: Cycle 6 左右スクロールボタンの半透明フロート（オーバーレイ）化と表示領域最大化

## 背景・目的
Cycle 5 で導通した「横スクロールアシスト機能」について、現在は表の上に2つの大きなボタン（`[◀ 左へスクロール]` `[右へスクロール ▶]`）が配置されています。
しかし、この構成では以下の明確な問題・UI上のデメリットがあります：
1. **マウスクリック時にわざわざ視線を逸らし、カーソルを一番上まで移動する必要がある。**
2. **ボタンコンテナの占有スペースによって、肝心の「シフト表が上下に表示できるエリア（縦の可認面積）」が縮小している。**

ユーザーの本物の理想は、**「シフト表（マトリクス）の左右の境界エリア中央付近に、半透明（グラスモフィズム）の丸い矢印ボタンがふわっと浮き出て（オーバーレイ）、そこをポチッと押すだけで心地よく左右へ横すべりできるデザイン」** です。

本サイクルでは、上部のダサい場所取りボタンを削除し、左右の画面中央・シフト切れ目部分への **「半透明フロート・横スクロールボタン（Chevron）搭載」** へとデザインとUXを劇的にアップグレードしてください。

## CCへの詳細実装指示 (P3)

### 1. 表上の旧スクロールボタン領域の全削除
- `App.jsx` において、表（マトリクス）の直上に配置されている `[◀ 左へスクロール]` `[右へスクロール ▶]` ボタンおよびその周囲の親コンテナ（`<div>` など）を**完全に削除**してください。
- これにより発生していた上部余白（マージン）を引き締め、シフト表本体の Y方向の可視行数を増やしてください。

### 2. 半透明フロートボタン（左右オーバーレイ）の実装
マトリクス本体を格納する親コンテナ（`position: relative` および `overflow: hidden` まわり、スクロールコンテナの外枠）に、`position: absolute` で以下のような半透明浮遊ボタンを左右に配置してください。

#### ◆ デザイン仕様（グラスモフィズム極意）
- 形状: 正円（`border-radius: 50%`）、サイズ: 直径 44px 〜 48px 前後
- 背景カラー・質感: `background: rgba(255, 255, 255, 0.75); backdrop-filter: blur(6px);` （※モード等にあわせつつも、下地がほんのり透ける半透明ホワイト、hover時に不透明度とシャドウを少し強くして感触を高める）
- シャドウ: `box-shadow: 0 4px 14px rgba(0,0,0,0.15);`、ボーダー: `border: 1px solid rgba(255,255,255,0.6);`
- アイコン: `lucide-react` の `ChevronLeft` または `ArrowLeft`, `ChevronRight` または `ArrowRight` (色: `#4F46E5` のようなブランドカラーまたは `#374151`、サイズ 24等)

#### ◆ 配置（ポジション）仕様
- 共通配置: `top: 50%; transform: translateY(-50%); z-index: 45;` (表の縦高ド真ん中、またはカレンダー表示領域の目線の届く心地よい位置)
- **右ボタン (次へ進む・右スイング)**: 
  - `right: 12px;` （または `16px` など画面右端・表の右端に寄った切れ目付近）
- **左ボタン (前へ戻る・左スイング)**: 
  - `left: 210px;` 前後 （※最重要：左側の **「スタッフ名前列が固定(Sticky)されている右端の切れ目」** 直後、つまりスクロールで可動するカレンダー領域の左端に沿った位置に置くか、または `scrollLeft` の計算に配慮して見やすい左脇へ置くこと。固定名前バッジにかぶりすぎない絶妙な間隔とすること）

#### ◆ スマート機能（賢い表示制御）
- 表コンテナのスクロールイベント（`onScroll`）と連動して状態を判定する：
  - もう **一番左端まで見えている場合（`scrollLeft === 0` 等）は「左の半透明ボタン」を非表示・不可視（opacity: 0 等）化する。**
  - **一番右端（限界）まできた場合も同様に「右の半透明ボタン」をフェードアウト・不可視にさせる。**
  ※これによって「まだ隠れている方向にだけ優しく光って導く」神UIが完成します！

### 3. バージョン更新
ヘッダー表示を **`v4.23` から `v4.24`** に更新してください。
